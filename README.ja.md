# ワークスペースファイルマネージャー（拡張版）

> **Fork について（tyly324）**：[Arrosam/dsh-better-workspace-file-manager](https://github.com/Arrosam/dsh-better-workspace-file-manager) の fork です。アップロード先の確認・進捗・再試行、削除ダイアログの自動クローズに加え、切り取り/コピー/貼り付け、名前変更、ZIP 圧縮/解凍、プロパティ、新規フォルダーなどを追加しました。元プロジェクトと同じ MIT ライセンスです。

DSH Web の「ファイル」タブとプレビューで使えるファイルマネージャーです。公式のファイルツリーに不足している書き込み操作を追加し、公式 DOM は変更しません。

## 機能

- **アップロード**：ボタン、ドラッグ＆ドロップ、フォルダー単位のドロップに対応。先に保存先（選択中のフォルダー、なければワークスペース直下）を確認し、ファイルごとの進捗・失敗理由・**再試行**を表示します。
- **複数選択**：クリック、⌘/Ctrl+クリック、Shift+クリック、空白部分のドラッグ選択。
- **ダウンロード**：単一ファイル、複数選択、フォルダー全体をストリーミングで ZIP にまとめます。
- **新規フォルダー**：右クリックメニューまたはヘッダーのボタン。最後に選んだフォルダー、なければルートに作成します。
- **削除**：確認後に完全削除。成功時はダイアログが必ず閉じ、行がすでに消えている場合は閉じて一覧を更新します。
- **切り取り / コピー / 貼り付け / 名前変更**：名前が衝突した場合は `name (1).ext` になり、上書きしません。
- **ZIP 圧縮 / 解凍**：解凍前に `..`、絶対パス、シンボリックリンク、暗号化エントリを検査します。
- **プロパティ**：名前、種類、サイズ（フォルダーは項目数）、更新日時、パーミッション、絶対パス。
- **ドラッグで移動 / 会話へドラッグ**：フォルダーへドラッグして移動、入力欄へドラッグして `@path` 参照を追加。
- **プレビュー**：各プレビューからダウンロード可能。テキスト/コード/Markdown はその場で編集でき、改行コードと BOM を保持し、バージョン競合を検出します。手動保存または 5 秒ごとの自動保存に対応。

## インストール

```sh
dsh plugin --profile web add github:tyly324/dsh-better-workspace-file-manager
```

要件：DSH Web プロファイル **0.2.1-rc.3 以降**（0.2.2-rc.1 で検証済み）、Host 側のローカルファイルシステム（fs-local / fs-sandbox）、Node.js 20.15 以降。

## 注意と制限

- 標準 **ZIP** のみ対応。ZIP64、暗号化 ZIP、7z、rar は未対応です。
- 1 ファイル / 1 アーカイブあたり 2 GiB、最大 10000 エントリ。大規模な処理はターミナルを使用してください。
- 削除は**完全削除**で、ゴミ箱はありません。
- ファイルのクリップボードは現在のページ内だけ有効で、再読み込みすると消えます。
- フォルダーのサイズは直下の項目数で、再帰的な合計サイズではありません。
